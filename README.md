# Дневник

Планировщик домашних заданий для Android: сегодня / неделя / предметы, напоминания и виджеты на рабочем столе.

Данные хранятся на телефоне. Установочный файл — [public/dnevnik.apk](public/dnevnik.apk).

## Установка

1. Скачайте `Dnevnik.apk`.
2. Откройте файл на телефоне и разрешите установку из этого источника.
3. Нажмите «Установить».

Виджеты: долгое нажатие на рабочем столе → «Виджеты» → «Дневник — сегодня» или «Дневник — список».

## Возможности

- Задания по предметам, сроку и приоритету
- Напоминания вечером, утром и перед уроком
- Виджеты с прогрессом на сегодня
- Всё остаётся после закрытия приложения

## Разработка

```bash
npm install
npm run dev
```

Сборка установочного файла — Android-проект в `android/` и веб-пакет через `vite.apk.config.ts`.
